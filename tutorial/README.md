# TinyWebServer C++ 入门教程

从零复现 [qinguoyi/TinyWebServer](https://github.com/qinguoyi/TinyWebServer)——一台 Linux 下的轻量级 C++ Web 服务器。本教程带你**边读边敲**:每个阶段都有完整可编译的代码、逐步讲解,以及可验证的验收清单。

---

## 这个教程帮你完成三件事

| 目标 | 怎么达成 |
|---|---|
| ① 从零复现本项目 | 分 9 个阶段逐步重建,每阶段都能跑、能验收,最终代码与原仓库对齐 |
| ② 熟悉 C++ | 前置 6 章基础(语法/类/RAII/模板/线程/现代特性),只讲项目用得上的部分 |
| ③ 熟悉构建与调试 | 全程用 CMake 构建,makefile 单独附录;gdb 入门在前、各阶段自然使用 |

## 如何使用本教程

1. **先看路线图**,明白现在在哪、要去哪。
2. **每篇文档都按"边读边敲"进行**:把文档里的代码在你自己的 `my_tiny_webserver/` 里**亲手敲一遍**(不要复制粘贴——敲的过程就是复现)。
3. **跑验收清单**:每篇文档都有"验收清单",照做并对照预期输出。全过 = 本阶段完成。
4. **打一个 git 提交**作为里程碑,随时可以回退对照。
5. **对照参考答案**:每阶段末尾的"与原项目对照"小节告诉你原仓库对应文件在哪、怎么 `diff`,卡住了就看答案。

> 你的复现代码统一放在 `my_tiny_webserver/`,随阶段增长,最终结构与原仓库一致。原仓库代码是你的"参考答案"。

## 环境要求

- **Windows 11 + WSL2**(本教程面向该环境,命令均基于 Ubuntu 24.04 验证)
- g++ ≥ 11(建议 13.x)、CMake ≥ 3.20、gdb
- MySQL 8(含 `libmysqlclient-dev`,供 Stage 8 连接)
- 可选:curl、telnet/nc(验收工具)、webbench(Stage 9 压测)
